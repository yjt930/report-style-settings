## 1. 模型逻辑

### 1.1 模型逻辑参考

- 外部参考文档：[MODOC 模型逻辑表](https://shimo.zhenguanyu.com/sheets/Aw65vQ7Oz6gVFyJM/MODOC)
- 该表用于承接模型侧更细的规则、字段口径和后续迭代；PRD 本节固化产品侧需要研发实现和验证的调用时机、输入结构、维度映射与边界。
- 若后续表格规则发生变化，需要同步更新本节的输入模板、调用原则和影响范围，避免产品 PRD 与模型侧配置不一致。

### 1.2 调用时机

在各模块输出默认评语之后，根据老师在「报告风格设置」中的选择，追加一次模型调用，按设定调整评语长度与语气风格。

### 1.3 模型输入说明

共分为三个部分：

**第一部分：原始输入**

沿用该模块默认调用时的原始输入。

例如旁批会输入：作文题、学生题目、按段落的作文内容等。

**第二部分：系统存的模型输出**

用「原始评语输出：」字段引出系统存的内容。

```text
原始评语输出：
{系统存的原始评语内容}
```

**第三部分：老师的要求**

用「用户要求：」字段引出用户的内容。

文案规则：

```text
用户要求：
不改变输出结构和原始评语的思路，用户现在希望将评语长度变得更{长度}，将评语风格变得更{风格}，请按照用户需求仅对评语内容进行优化。
```

**完整输入结构**

```text
{第一部分：原始输入}

原始评语输出：
{系统存的原始评语内容}

用户要求：
不改变输出结构和原始评语的思路，用户现在希望将评语长度变得更{长度}，将评语风格变得更{风格}，请按照用户需求仅对评语内容进行优化。
```


### 1.4 维度选项

#### 评语语气

| 选项 | 说明 |
| ---- | ---- |
| 均衡型 | 不做改变 |
| 直接型 | 更直给，少铺垫，突出待改点 |
| 鼓励型 | 先肯定优点，再给出改进建议 |
| 启发型 | 以提问引导，帮助学生自己思考 |

#### 评语长度

| 选项 | 说明 |
| ---- | ---- |
| 简洁型 | 压缩篇幅，保留核心问题与建议 |
| 均衡型 | 不做改变 |
| 详细型 | 展开说明，补充原因与改法 |

### 1.5 调用原则

- 每次仅基于**该模块默认调用的输入/输出**，追加老师定义的评语风格要求，生成新的评语；**不在同一对话中无限追加上下文**。
- 不同语气 × 长度组合对应**独立版本**，各自独立编辑和保存。
- 若语气、长度均为默认（均衡型 + 均衡型），**不请求模型**，直接使用默认评语。

### 1.6 影响范围

**受影响模块**

- 亮点（一、二稿）
- 深度诊断
- 旁批
- 整体/要求评语
- 病句
- 写作提升
- 修改精析
- 学法指导

**不受影响模块**

- 别字
- 分数
- 润色
