## 1. 模型逻辑

### 1.1 调用时机

在各模块输出默认评语之后，根据老师在「报告风格设置」中的选择，追加一次模型调用，按设定调整评语长度与语气风格。

### 1.2 追加输入

不改变 assistant 原有输出结构和评语整体思路，仅追加风格约束：

> 不改变 assistant 输出结构和评语整体思路，用户现在希望将评语长度 {长度}，将评语风格 {风格}，请按照用户需求仅对评语内容进行优化。


### 1.3 维度选项

#### 评语语气

| 选项 | 说明 |
| ---- | ---- |
| 常规型 | 不做改变 |
| 直接型 | 更直给，少铺垫，突出待改点 |
| 鼓励型 | 先肯定优点，再给出改进建议 |
| 启发型 | 以提问引导，帮助学生自己思考 |

#### 评语长度

| 选项 | 说明 |
| ---- | ---- |
| 简洁型 | 压缩篇幅，保留核心问题与建议 |
| 常规型 | 不做改变 |
| 详细型 | 展开说明，补充原因与改法 |

### 1.4 调用原则

- 每次仅基于**该模块默认调用的输入/输出**，追加老师定义的评语风格要求，生成新的评语；**不在同一对话中无限追加上下文**。
- 不同语气 × 长度组合对应**独立版本**，各自独立编辑和保存。
- 若语气、长度均为默认（常规型 + 常规型），**不请求模型**，直接使用默认评语。

### 1.5 影响范围

**受影响模块**

- 亮点（一、二稿）
- 深度诊断
- 旁批
- 整体/要求评语
- 病句
- 写作提升
- 修改精析
- 学法指导

**不受影响模块**

- 别字
- 分数
- 润色
